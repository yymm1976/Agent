## 审查总结

本次审查共识别出 **41 个 MCP 低度节点（in_degree=0）** 与 **392 个 dead exports**（来自 `dead-code-report.json`）。经 `trace_path` 反向验证，大量模块在生产入口（CLI `src/index.tsx`、Desktop `desktop/main/index.ts`、Renderer `desktop/renderer/src/main.tsx`）中无调用路径，确认为死代码或可选但未启用子系统。

主要问题集中在：
1. **完整死代码子系统**：`src/channels/`（Slack/Telegram/Webhook）、`src/evaluation/`（BFCL 评估器 / EvalRunner）、`src/optional/voice/`（语音管理器）无任何生产调用。
2. **重复实现**：`src/memory/rejected-alternative-store.ts` 与 `src/agent/rejected-alternative-store.ts` 同时存在，前者无生产调用。
3. **功能残缺 / 占位实现**：`openai-whisper`/`openai` TTS、`tournament` 聚合模式、`ClaudeMCPBridge.importFromClaudeConfig`、部分 Desktop Settings UI 未实现。
4. **类型 / 错误类误出口**：`src/config/schema.ts` 大量 Zod Schema 对象被导出但仅用于类型推断；`src/utils/errors.ts` 中 `LLMError` / `PermissionDeniedError` / `SecurityViolationError` 无生产使用。

整体建议：**Important 级别问题需分批清理**，优先删除确认无生产调用的整文件/整子系统；对功能残缺模块需明确是否继续投入或标记为实验性并默认关闭。
